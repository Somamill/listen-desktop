# Getting started

A production signed/notarized independent installer is not yet available. Build locally using README.md; do not bypass Gatekeeper for a purported official release. Check https://github.com/Somamill/listen-desktop/releases for future verified packages.

1. Open your locally built listen.app. Its separate desktop identity preserves existing desktop settings and does not replace sovo.
2. Settings → Client: leave Default torrent app for magnet handoff, or configure a supported client’s Web/RPC address and credentials. Use local paths only for a client on this Mac.
3. Choose local downloads and a separate finished-library folder. A cloud destination is optional; download locally first and move completed books only when requested.
4. Search for an edition you are authorized to use. Verify title, author, language, narrator and format before sending it.
5. Troubleshoot using Downloads and Settings. Unknown health is not proof of an unsafe or incomplete file; good health is not proof of safety. Provider/client failures do not disable TLS validation.

Goodreads sign-in is optional in the app-owned window, with CSV/browser alternatives. Interface language follows supported system preferences by default and can be selected in Settings independently of audiobook-language filters. Updates are checked without installing or executing anything.
