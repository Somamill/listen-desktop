# listen. desktop design

Independent audiobook discovery and library app, separate from sovo. and dot. Slate blue and cool neutrals, quiet glass surfaces, readable system typography and cover-led results. Existing discovery, search, client settings and library remain Operate/Read interfaces; no promotional hero inside app screens.

Use stable semantic tokens, visible keyboard focus, native window/titlebar and real errors with recovery. Respect reduced motion and RTL. Public screenshots contain permitted fixtures, never private owner libraries. UI metadata names/audio languages are separate from interface language. Impeccable/Hallmark assess the web surface; native launch, window and menu checks remain separate.

## Extraction audit decisions

All component colors and font families are declared in local tokens; no shared suite runtime dependency. Functional small text was increased, labels keep normal casing, focus/disabled controls expose multiple visual channels, fields have a stronger border, and icons use one original line family. The identity uses a steel-blue sound aperture. Legacy component spacing remains during this extraction: mechanically rounding every pre-existing dimension to a 4px grid would reshape otherwise working forms. The native window supports widths850px and up; 320px browser wrap warnings are outside the Mac window contract. Text measures are capped, and Arabic/German rendered checks remain mandatory. Hallmark spacing reflexes are recorded as retained-source exceptions, not passed checks.

## Liquid Glass desktop

Keep the Liquid Glass treatment on navigation, search, dialogs, and the floating settings action bar. These layers sit above solid reading and data surfaces. Use system typography, short route headings and a neutral sound-aperture mark. The sidebar is inset from the window and mirrors for RTL. Reduced transparency replaces material with an opaque surface, and reduced motion removes authored transitions. The Mac icon and browser PNG are generated from the same Swift source.

About listen. uses the standard macOS About panel, with localized creator and feedback text and links for email, project source, Max’s Reddit profile and optional Ko-fi support. The project keeps its independent listen. identity.
